Credit Risk Classification

Robust classification and algorithmic fairness testing for credit default predictions.

Business Problem

Traditional risk evaluation frameworks rely heavily on manual procedures. This makes processes slow and creates inconsistencies, leading to higher default rates or false positives that reject creditworthy applicants.

Solution

Developed predictive risk classifiers using ensemble algorithms. To address severe default imbalance, the project implements resampling pipelines and hyperparameter optimization, validated against demographic parity and equalized odds to guarantee algorithmic fairness.

Methodology

1. Data Ingestion & Imbalance Correction: Addressed severe class skew (low default ratios) by applying SMOTE (Synthetic Minority Over-sampling Technique) in combination with random under-sampling pipelines.

2. Model Experimentation: Trained and benchmarked classifiers including Random Forest, XGBoost, and tuned Logistic Regression models.

3. Optimization & Slicing: Selected model parameters through cross-validated Grid Search. Checked decision boundaries and set prediction thresholds prioritizing Recall to minimize false negatives (default leaks).

4. Fairness & Bias Assessment: Evaluated models against demographic subsets, computing risk ratio metrics and equalized odds to ensure predictions were unbiased across key user subgroups.

Key Results

  • ✔ Achieved 91% Recall on high-risk classifications, protecting lending portfolios from undetected delinquencies.
  • ✔ Secured a test partition ROC-AUC score of 0.89.
  • ✔ Verified zero statistically significant demographic bias, satisfying fair-lending requirements.
