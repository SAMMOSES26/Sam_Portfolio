Business Problem

Educational institutions often rely on historical examination results to assess student performance, limiting their ability to identify at-risk students before academic outcomes decline. This project demonstrates how machine learning can be applied to predict mathematics scores using demographic, academic, and behavioural attributes, enabling earlier data-driven interventions and more targeted student support strategies.

Solution

Developed an end-to-end machine learning application that predicts student mathematics scores using demographic, academic, and behavioural attributes.

The solution implements a modular machine learning pipeline consisting of:

  • • Data Ingestion
  • • Data Transformation
  • • Feature Engineering
  • • Model Training
  • • Model Selection
  • • Model Evaluation
  • • Model Serialization
  • • API Development
  • • Prediction Pipeline
  • • Docker Containerization
  • •CI/CD Automation
  • • Cloud Deployment

Multiple regression algorithms were trained, evaluated, and optimized using GridSearchCV-based hyperparameter tuning techniques, with Linear Regression selected as the final model after achieving the best predictive performance (R² = 0.8804).

Predictions are served through a Flask web application and REST API, demonstrating the complete machine learning lifecycle from data preparation to cloud deployment.

To demonstrate deployment and DevOps practices, the application was deployed using two AWS-based approaches:

  • • AWS Elastic Beanstalk + AWS CodePipeline (Managed PaaS Deployment)
  • • Docker + GitHub Actions + Amazon ECR + Amazon EC2 (Containerized Deployment)

Methodology

  1. Data Collection: Gathered a dataset containing 1,000 student records with academic, demographic, and behavioural attributes.
  2. Data Ingestion: Loaded the student performance dataset and organized raw data for downstream preprocessing and model training.
  3. Data Cleaning & Transformation: Processed missing values, validated formats, encoded categorical variables, and scaled numerical features.
  4. Exploratory Data Analysis (EDA): Analyzed feature distributions, correlations, and relationships between predictor variables and target outcomes.
  5. Train-Test Split: Partitioned data into 80% training and 20% testing datasets for unbiased model evaluation.
  6. Model Training & Selection Trained and compared multiple regression algorithms including Linear Regression, Random Forest, Decision Tree, Gradient Boosting, AdaBoost, CatBoost, and KNN Regressor using GridSearchCV-based hyperparameter tuning and model selection.
  7. Model Evaluation: Compared model performance using regression metrics and selected Linear Regression as the final model, achieving an R² score of 0.8804.
  8. Model Serialization: Serialized the trained model and preprocessing pipeline as .pkl artifacts for deployment and inference.
  9. Prediction Pipeline: Implemented a prediction workflow that applies preprocessing and generates score predictions from new inputs.
  10. Flask API Development: Developed a Flask-based web application and REST API for serving predictions.
  11. Docker Containerization: Containerized the application for consistent deployment across environments.
  12. CI/CD Automation: Configured GitHub Actions and AWS CodePipeline for automated build and deployment workflows.
  13. Cloud Deployment: Deployed the application using two strategies: AWS Elastic Beanstalk with AWS CodePipeline and a containerized deployment pipeline using Docker, GitHub Actions, Amazon ECR, and Amazon EC2.
